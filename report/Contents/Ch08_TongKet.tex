\section{Ưu điểm nổi bật}
\label{sec:tk-uu-diem}

\begin{enumerate}
    \item \textbf{Kiểm soát tương tranh hai tầng:} Kết hợp \texttt{pg\_advisory\_xact\_lock} (tuần tự hóa yêu cầu, giới hạn 3 đơn chờ) với ràng buộc \texttt{EXCLUDE USING gist} ở tầng CSDL, loại bỏ hoàn toàn nguy cơ đặt trùng lịch (Double Booking) ngay cả khi nhiều yêu cầu đồng thời.
    \item \textbf{Thanh toán VietQR tự động, an toàn lỗi:} Tạo mã QR động theo đơn hàng, đối soát chữ ký HMAC-SHA256, đảm bảo Idempotency và xử lý Ghost Payment (chuyển tiền muộn sau khi đơn bị hủy).
    \item \textbf{Trợ lý AI có kiểm soát (Proposal-Confirmation):} Gemini 1.5 Flash chỉ sinh thẻ đề xuất cho các thao tác ghi dữ liệu, buộc người dùng xác nhận trước khi thực thi, ngăn ngừa AI thay đổi dữ liệu trái phép.
    \item \textbf{Trải nghiệm người dùng trực quan:} Sơ đồ mặt bằng SVG tương tác hiển thị trạng thái chỗ ngồi thời gian thực; check-in dung sai $\pm 30$ phút; quản lý dịch vụ phát sinh Running Tab.
    \item \textbf{Hiệu năng và triển khai tối ưu:} Docker Multi-stage build (215MB), gói Front-end Gzip 193kB trên Vercel Edge CDN; thời gian tải trang và độ trễ API đáp ứng yêu cầu phi chức năng.
    \item \textbf{307 ca kiểm thử tự động:} Bao phủ các luồng nghiệp vụ quan trọng, hỗ trợ phát hiện lỗi hồi quy khi nâng cấp mã nguồn.
\end{enumerate}

\section{Hạn chế}
\label{sec:tk-han-che}

\begin{enumerate}
    \item \textbf{Kiểm thử tích hợp chưa dùng CSDL thật:} 307 ca kiểm thử chạy trên Mockito và CSDL giả lập trong bộ nhớ. Các kịch bản SQL đã kiểm tra riêng trên PostgreSQL thật, nhưng chưa tích hợp Testcontainers vào quy trình CI/CD.
    \item \textbf{Hoàn tiền còn bước thủ công:} Hệ thống tự động tính phí phạt và ghi nhận số tiền hoàn, nhưng việc chuyển khoản hoàn tiền vẫn cần Quản lý chi nhánh phê duyệt thủ công.
    \item \textbf{Tác vụ định kỳ đơn phiên bản:} \texttt{BookingExpiryScheduler} và bộ nhớ đệm hoạt động trong bộ nhớ máy chủ. Khi mở rộng nhiều phiên bản (Horizontal Scaling) cần bổ sung khóa phân tán (Distributed Lock).
    \item \textbf{Chưa có ứng dụng di động và IoT:} Hệ thống hoạt động trên nền Web Responsive, chưa xây dựng Native Mobile App và chưa tích hợp khóa cửa điện tử IoT.
\end{enumerate}

\section{Hướng phát triển}
\label{sec:tk-huong-phat-trien}

\subsection{Ngắn hạn}

\begin{itemize}
    \item \textbf{Testcontainers và kiểm thử E2E:} Tích hợp PostgreSQL thật qua Testcontainers trong CI/CD; bổ sung kiểm thử giao diện tự động bằng Playwright.
    \item \textbf{Redis và ShedLock:} Thay bộ nhớ đệm nội bộ bằng Redis Cluster; dùng ShedLock đồng bộ tác vụ định kỳ khi mở rộng đa phiên bản.
    \item \textbf{Rate Limiting:} Tích hợp Bucket4j + Redis Token Bucket cho các API nhạy cảm (đăng nhập, thanh toán, Gemini AI).
    \item \textbf{Bảo mật phiên:} Chuyển Access Token từ \texttt{localStorage} sang Cookie \texttt{HttpOnly}, \texttt{Secure}, \texttt{SameSite=Strict} để chống XSS.
\end{itemize}

\subsection{Dài hạn}

\begin{itemize}
    \item \textbf{Ứng dụng di động:} Phát triển app iOS/Android bằng React Native hoặc Flutter; hỗ trợ Push Notification, quét QR và đăng nhập sinh trắc học.
    \item \textbf{Tích hợp IoT:} Kết nối khóa cửa thông minh và cảm biến hiện diện qua MQTT; tự động sinh mã PIN/QR mở cửa theo khung giờ đặt chỗ.
    \item \textbf{Multi-Tenancy SaaS:} Nâng cấp kiến trúc để nhiều doanh nghiệp văn phòng chia sẻ độc lập cùng sử dụng trên một hạ tầng tập trung.
    \item \textbf{Gợi ý đối tác bằng Vector Embeddings:} Dùng mô hình nhúng ngữ nghĩa kết hợp \texttt{pgvector} để phân tích hồ sơ chuyên sâu hơn thuật toán Jaccard hiện tại.
\end{itemize}

\section{Kết luận}
\label{sec:tk-ket-luan-chung}

Đề tài đã hoàn thành tất cả 12 mục tiêu nghiệp vụ và kỹ thuật đề ra. Hệ thống CoSpace vận hành ổn định trên nền tảng đám mây, giải quyết được các bài toán cốt lõi: kiểm soát tương tranh đặt chỗ, thanh toán trực tuyến an toàn, và kết nối cộng đồng thành viên. Quá trình thực hiện đồ án đã giúp nhóm tích lũy kinh nghiệm thực tế về thiết kế kiến trúc phần mềm, kiểm thử tự động và quy trình phát triển Agile -- là nền tảng để tiếp tục phát triển sản phẩm trong tương lai.
