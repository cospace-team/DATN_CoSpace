# Database Seeds — CoSpace

> Thư mục này chứa SQL seed scripts để khởi tạo dữ liệu mẫu cho development và testing.

## Danh sách

- [ ] `seed_users.sql` — Super Admin, Branch Admin, Staff, Customer mẫu
- [ ] `seed_branches.sql` — Chi nhánh, tầng, workspace mẫu
- [ ] `seed_pricing.sql` — Bảng giá global + branch override
- [ ] `seed_services.sql` — Dịch vụ bổ sung mẫu
- [ ] `seed_tags.sql` — Tags kỹ năng/sở thích cho matching
- [ ] `seed_policies.sql` — Chính sách hủy mẫu
