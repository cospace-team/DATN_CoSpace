# User Stories — CoSpace

> Thư mục này chứa User Stories theo từng Epic/Sprint.

## Format

```
[EPIC-ID] Là một <vai trò>, tôi muốn <hành động>, để <giá trị>.

Acceptance Criteria:
- AC1: ...
- AC2: ...
```

## Danh sách Epic

| Epic | Module | Sprint |
|------|--------|--------|
| A | Identity & Phân quyền | Sprint 1 |
| B | Space + Availability | Sprint 2 |
| C | Booking + Pricing | Sprint 3 |
| D | Payment + Check-in | Sprint 4 |
| E | Cancellation + Matching + Dashboard | Sprint 5 |
| F | Quality + Release | Sprint 6 |

> Chi tiết User Stories sẽ được tạo dần khi phân tích từng module.
